# La Légende des Temps (Hyrule Conjugaison)

Jeu d'entraînement à la conjugaison française dans l'univers de Zelda : quinze temps (indicatif, subjonctif, conditionnel, impératif), un univers par temps, 241 verbes groupés en familles. Un seul fichier HTML, sans dépendance.

Jouer : https://julienhagege.github.io/hyrule-conjugaison/
